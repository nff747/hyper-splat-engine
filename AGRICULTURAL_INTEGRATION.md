# Agricultural Edge Integration & Field Telemetry

### Zero-Connectivity Sensor Ingestion
- Standardized binary serialization format for offline NPK, soil moisture, and leaf wetness sensors.
- Optimized memory buffer encoding for microsecond edge processing on low-power ARM/RISC-V nodes.

### Evapotranspiration Ingestion Pipeline
- Integrated FAO-56 Penman-Monteith reference evapotranspiration (ET0) telemetry into simulation state.
- Dynamic variable-rate water requirement adjustments based on real-time microclimate inputs.
